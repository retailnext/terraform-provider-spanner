# Resource spanner_role

Manages a Spanner database role used for [fine-grained access control
(FGAC)](https://cloud.google.com/spanner/docs/fgac-about). A role is purely a named container:
it has no attributes of its own (no login/password, unlike some other databases' roles) - grant
privileges and role membership to it via `GRANT ... TO ROLE` statements (managed by a separate
resource once added). Spanner has no rename-role DDL, so changing `name` forces the role to be
dropped and re-created.

## Example Usage

```terraform
# Manage a database role. Roles are named containers for privileges and
# role membership - see the spanner_grant resource for privileges.
resource "spanner_role" "app_reader" {
  name = "app_reader"
}
```
