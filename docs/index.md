# Spanner ACL Provider

Use the Spanner ACL provider to manage fine-grained access control (FGAC) in a
[Google Cloud Spanner](https://cloud.google.com/spanner) database, including database roles,
privilege grants, and role membership. The provider authenticates using the standard GCP client
library scheme (Application Default Credentials by default) - see the
[Authentication](guides/authentication) guide for details. Note that this provider does not
manage the lifecycle of Spanner instances or databases themselves. It is focused on access
control management within a single, already-existing database.

## Example Usage

```terraform
# Authenticate with Application Default Credentials (recommended)
provider "spanner" {
  project  = "my-gcp-project"
  instance = "my-spanner-instance"
  database = "my-database"
}
```

## Environment Variables

The following environment variables are supported. They are read first; an explicit provider attribute overrides them.

| Variable | Provider Attribute | Description |
|---|---|---|
| `SPANNER_PROJECT` | `project` | GCP project ID containing the target Spanner instance |
| `SPANNER_INSTANCE` | `instance` | Spanner instance ID |
| `SPANNER_DATABASE` | `database` | Spanner database ID to manage ACL objects on |
| `SPANNER_CREDENTIALS` | `credentials` | Inline service account JSON key content |
| `GOOGLE_APPLICATION_CREDENTIALS` | — | Path to a service account key file, used by Application Default Credentials when no provider-level credentials are set |

See the [Authentication](guides/authentication) guide for the full set of supported credential
sources and the IAM permissions required.

## Schema

### Optional

- `credentials` (String, Sensitive) Inline JSON service account key content to authenticate with, as an alternative to Application Default Credentials. Mutually exclusive with `credentials_file`. Can also be set via the `SPANNER_CREDENTIALS` environment variable.
- `credentials_file` (String) Path to a JSON service account key file to authenticate with. Mutually exclusive with `credentials`.
- `database` (String) The Spanner database ID to manage ACL objects on. Can also be set via the `SPANNER_DATABASE` environment variable.
- `instance` (String) The Spanner instance ID. Can also be set via the `SPANNER_INSTANCE` environment variable.
- `project` (String) The GCP project ID containing the target Spanner instance. Can also be set via the `SPANNER_PROJECT` environment variable.
